Result shape (D-19, plus the planner's optional top-level reason per RESEARCH Open Question 1):
expect_result = { status: 'verified'|'unmet'|'uncertain', checks: [{ kind, expected, observed, status: 'met'|'unmet'|'uncertain' }], waited_ms: integer, timeout_ms: integer, reason?: one of EXPECT_UNCERTAIN_REASONS, present only when status === 'uncertain' }
Check list order is fixed: url_includes, title_includes, text_visible, text_gone, state, value, dialog_open. For a selector: a state check (expected = state, or 'visible' when neither state nor value is given) and/or a value check (expected = value). expected/observed strings pass through capObserved; observed is null when not observable.

Functions:
- clampExpectTimeoutMs(raw) → integer in [0, 5000]; non-finite or absent → 2000; numeric strings accepted; values truncated toward zero.
- normalizeExpectSpec(raw) → { ok: true, spec: { timeoutMs, checks: [{ kind, expected, selector?, sensitiveHint? }] } } | { ok: false, reason: 'invalid_expect', detail }. Rejects: non-plain-object, unknown key, wrong type, an empty string in any field except `value` (D-13 types value as a plain string, and `value: ''` is the natural clear_input check), string longer than EXPECT_STRING_MAX, state not in EXPECT_STATES, state or value without selector, no predicate key. Mirrors the MCP zod validation (plan 69-06) so a newer or older MCP cannot drive the evaluator with a malformed spec.
- aggregateExpectStatus(checks) → 'verified' if non-empty and every check met; else 'unmet' if any unmet; else 'uncertain'.
- capObserved(value) → strings longer than 120 become the first 117 chars + '...'; non-strings unchanged.
- isRedactedField({ tag, type, autocomplete, name, id }) → true for input type password or hidden, autocomplete current-password / new-password / one-time-code / any 'cc-' token, or name/id/autocomplete matching EXPECT_SENSITIVE_NAME_SOURCE.
- buildUncertainExpectResult(spec, reason) → every check uncertain with observed null; waited_ms 0; timeout_ms spec.timeoutMs (or the default when spec is null); status 'uncertain'; reason.
- _fsbExpectProbeInPage(probeSpec) → self-contained, read-only page function (no closures over SW scope, no timers, no MutationObserver, no requestAnimationFrame). probeSpec = { checks, textScanMax, shadowHostBudget, observedMax, redacted, sensitiveNameSource }. Returns { ok: true, observations: [{ kind, observable, holds, observed, redact, reason? }], textTruncated } or { ok: false, error }.
- evaluateExpectation({ tabId, spec, deps, commit, pageUnresponsive }) → Promise<expect_result>; never throws (internal errors become status uncertain, reason 'evaluator_failed').
  deps = { tabsGet(tabId) → Promise<tab|null> (tab: { url, title, status, pendingUrl }), executeProbe(tabId, func, args) → Promise<{ ok, result, documentId, reason }> (reason 'timeout' when the 750 ms race was lost), now() → number, sleep(ms) → Promise }
  commit (optional, nav tools only) = { required: boolean, isCommitted() → boolean, documentId() → string|null }
